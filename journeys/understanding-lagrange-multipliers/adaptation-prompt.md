# Adaptation consultation prompt — Understanding Lagrange Multipliers

Copy this prompt into an AI assistant when developing a Learning Journey brief for your own teaching context.

---

I want help drafting a commissioning brief for a PRISM Learning Journey.

**My subject / topic / teaching challenge:**
[Describe a formal method learners can execute without understanding why it works, what it means geometrically or conceptually, or when its conclusions are justified.]

**Who the learners are:**
[Level, discipline mix, prior knowledge]

**Time available:**
[Learning time and calendar span, if known]

Please help me clarify, in order:

1. **Intended capability** — what learners should become better able to interpret, justify and transfer, not only calculate.
2. **Where procedure outruns understanding** — algebra without meaning, visual relationships skipped, or unjustified conclusions from candidate solutions.
3. **How learning should progress** — for example concrete situation → visual/structural insight → formal representation → evaluation of claims → independent transfer.
4. **What the culminating task must require** — especially whether learners must justify a global or warranted conclusion, not only compute a stationary or candidate answer.
5. **Constraints** — prior knowledge, tools, accessibility, and whether a Learning Journal is needed (it is fine to omit one deliberately).

Use the exemplar Learning Journey “Understanding Lagrange Multipliers” only as an illustration of one possible design logic:

- Teaching need: learners can perform constrained-optimisation algebra without understanding why multipliers work or when conclusions are justified.
- Sequence idea: constrained-choice reasoning → gradients/tangency → formal equations → limits of inference → diagnosis of claims → independent justified application.
- Transferable idea: Concrete → Visual → Formal → Transfer with explicit evaluation of mathematical claims before independent transfer; the Lagrange scenario is not what to copy.

Do **not** assume I want the same mathematics topic, the same product mix, or a Learning Journal. Propose a brief that fits **my** teaching challenge. If this progression fits, say why; if another structure fits better, prefer that.

Return a structured commissioning brief I can paste into PRISM (purpose/focus, learners, learning time, duration, constraints), without inventing validation evidence or claiming the exemplar’s original brief as mine.
